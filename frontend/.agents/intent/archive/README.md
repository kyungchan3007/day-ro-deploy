# 의도 아카이브

이 디렉터리는 완료되거나 대체된 의도를 월별로 접어 보관한다.

## 목적
- 활성 의도 목록을 작게 유지한다.
- 오래된 작업/SDD 파일을 매번 읽지 않게 한다.
- 과거 결정은 삭제하지 않고 요약과 링크로 추적한다.

## 권장 파일명
- `YYYY-MM.md` (완료된 의도를 월별로 모은다)

## 압축 블록 스키마
각 완료 의도는 아래 필드를 가진 블록 하나로 접는다. 이 블록이 과거 결정의 1차 인터페이스이므로, "무엇"뿐 아니라 "왜(근거·제약)"까지 담아 전문 없이도 후속 작업이 판단할 수 있게 한다.

```md
## <task_id>
- domain: <도메인 태그 (조회 grep 기준)>
- 의도: <한 줄>
- 결정: <유지되는 경계/설계 결정>
- 근거/제약: <이후에도 지켜야 하는 이유·제약. 없으면 "없음">
- 검증: <approved | approved_with_notes | ...> (reports/validation/<file>.md)
- superseded_by: <있으면 task_id, 없으면 - >
- 원본: <git-ref> sdd/<file>.md, tasks/<file>.md
```

- `원본`의 `<git-ref>`는 해당 파일을 마지막으로 담은 커밋 해시다. 전문은 `git show <ref>:<path>`로 꺼낸다.
- `domain`은 `.agents/domain/*.md` 이름 기준으로 적어 grep 가능하게 한다.

## 규칙
- 진행 중이거나 차단된 의도는 아카이브하지 않는다.
- 원본 삭제는 git에 커밋된 파일만 대상으로 한다(미커밋 삭제 금지). 전문은 git이 보관한다.
- 아카이브 전 기존 참조가 깨지지 않는지 확인한다.
- 실제 파일 이동/삭제/병합은 배치로 모아 사용자 승인 후 진행한다.
