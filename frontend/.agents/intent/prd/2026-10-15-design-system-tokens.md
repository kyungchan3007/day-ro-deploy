## 문제
- 글자 크기를 화면마다 임의값으로 씀 (`text-[13px]` 등 tsx 50여 곳 · css module `font-size: 13px` 40여 곳)
- 그림자 · 딤 · 흰 글자 · 에러 박스 · 모션 시간 · z-index · 일부 radius 가 토큰 없이 값으로 흩어짐
- 바텀시트 껍데기 · 빈 상태 · 내비 제목이 슬라이스마다 같은 코드로 중복
- 스토리북에 토큰 문서가 없고, 공용 컴포넌트 일부 스토리 누락
- 토큰을 우회해도 막는 장치가 없음 → 다시 흩어짐

## 목표
- 화면 코드는 의미 토큰만 쓴다 (예외는 이유와 함께 목록화)
- 화면 모양은 그대로 (리팩터링) — 의도한 차이는 PR 에 근거와 함께 명시
- 중복 UI 는 `shared/ui` 공용 컴포넌트로
- 스토리북 = 토큰 · 컴포넌트 단일 문서
- 재발 방지: 단위 테스트가 토큰 우회를 잡는다
