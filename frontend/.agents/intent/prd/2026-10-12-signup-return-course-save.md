## 문제
- 비로그인 상태로 코스 저장 → 카카오 로그인·회원가입 → 상황입력 1단계(시간)로 이동, 입력 데이터 유실 (MO-AOS · MO-iOS)
- 사용자 영향: 만든 코스를 처음부터 다시 만들어야 함 → 첫 저장(가입 전환) 이탈

## 목표
- 로그인·회원가입 후 코스 저장 화면으로 복귀
- 저장 시트에 입력한 코스명·설명으로 저장을 이어서 처리 → "코스가 저장되었습니다." 토스트

## 비목표
- 저장 전 로그인 유도 화면 · 문구 변경
- 다른 보호 화면(마이페이지 등) 복귀 정책 변경
- 카카오 로그인 방식 변경 (앱 전환 · 새 탭 여부는 그대로)

## 성공 기준
- 로그인 후 같은 탭 · 새 탭 어느 쪽으로 돌아와도 코스 화면 복원 + 저장 완료 토스트 (e2e)
- 보관 데이터 만료(30분) · 손상 시 안전하게 무시 (단위 테스트)
