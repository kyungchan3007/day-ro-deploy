## 문제
- 찜한 코스 "길안내 공유" 링크를 카카오톡에 보내면 네이버 미리보기 노출
  - 제목 "네이버지도 - 길찾기" · 설명 경로 내용 · 네이버 플레이스 이미지
- 사용자 영향: 받은 사람이 데이로 코스라는 걸 알 수 없음 → 브랜드 노출 · 유입 기회 손실

## 목표
- 미리보기 제목 "데이로-코스 일정"
- 미리보기 설명 "{닉네임}님의 코스 일정을 확인해 보세요!" (사용자 결정: 닉네임 포함)
- 미리보기 이미지: 시안(피그마 192-12285) 배경 · 로고 · 일러스트
- 링크를 연 사람은 지금처럼 네이버 길찾기(출발 → 경유지 → 도착 도보)로 이동

## 비목표
- 이미지 안 "***님" 문구 (닉네임 동적 이미지) → 후속 후보
- 카카오 공유 SDK 카드 "일정 확인하기" 버튼 → 후속 후보
- 데이로 자체 공유 코스 화면 (백엔드 공개 API 필요)

## 성공 기준
- 공유 링크 = 데이로 `/share/course/` 주소, 페이지 head 에 og 제목 · 설명 · 이미지 (e2e)
- 공유 페이지 진입 → 네이버 길찾기 주소로 이동 (e2e)
- 잘못된 좌표 · 장소 수 · 길이 → 이동하지 않고 안내 (단위 테스트)
