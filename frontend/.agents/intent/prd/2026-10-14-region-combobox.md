## 문제
- "② 동네"가 검색창 + 아래로 길게 펼쳐지는 결과 목록
- 검색어를 알아야만 동네를 고를 수 있음 (구를 골라도 목록이 안 보임)
- 회의 결정: 드롭다운으로 변경 → C안 (드롭다운 + 검색 겸용)

## 목표
- 동네 칸을 누르면 드롭다운이 열리고, 고르거나 검색할 수 있음
- 인기 검색어는 드롭다운 맨 위에 항상 표시
- 구를 골랐으면 그 구의 동네 전체 목록을 바로 표시
- 선택 없이도 접을 수 있음 (▾ · 칸 다시 누르기 · 바깥 누르기 · Esc)

## 비목표
- 지역 데이터 · 인기 검색어 API 변경
- 구 선택(①) 드롭다운 변경
- 동네 다중 선택

## 사용자 시나리오
- 구 선택 → 동네 칸 누름 → 인기 검색어 + 구 동네 전체 → 하나 고름 → 닫힘 · 다음 활성
- 구 미선택 → 동네 칸 누름 → 인기 검색어 + "구를 먼저 고르면 동네 전체가 보여요" 안내
- 입력 → 같은 드롭다운에서 결과 좁힘 (일치 글자 강조, 전역 검색은 구 이름 함께)
- 구 미선택 · 다른 구의 인기 검색어 선택 → 구 칸 자동 변경
- 결과 없음 → "찾는 동네가 없어요" 안내
- 선택 없이 접음 → 다음 버튼 비활성 유지

## 유지
- 동네 별칭 검색 (예: 서촌)
- 구 변경 · 검색어 삭제 시 동네 초기화 (#168)
- 뒤로가기 입력값 복원
