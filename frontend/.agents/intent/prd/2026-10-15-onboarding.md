## 문제
- 처음 들어온 사람이 서비스 소개 없이 바로 홈 카드 2개만 봄
- 회원 · 비회원 구분 없이 같은 화면 → 비회원에게 로그인 · 둘러보기 선택지가 없음

## 목표
- 비회원 `/` → 시작 화면 (카카오 로그인 · 로그인 전 둘러보기)
- 둘러보기 → 온보딩 3장(서울 · AI 추천 · 저장/공유) → 홈
- 회원 `/` → 바로 홈

## 사용자 결정 (2026-10-15)
- 시작 화면: 비로그인이면 방문마다 노출 → 둘러보기 선택은 세션 쿠키(브라우저 닫으면 해제)
- `/login` 유지 (로그인 필요 상황 · 원래 화면 복귀)
- 시안 전용 색은 토큰 추가, 폰트는 현재 유지
- 온보딩 마지막 장 버튼 "시작하기"

## 범위 밖
- 폰트(Pretendard) 교체, 시안의 임시 핀 로고(공식 로고 사용), 시안 푸터 모양(현재 홈 푸터 유지 — 시안 표기 "홈과 동일")

## 성공 기준
- 비회원 첫 진입 시작 화면, 둘러보기 → 3장 → 홈, 같은 방문 재진입 홈 · 새 방문 시작 화면
- 회원 쿠키 → 홈, 시작 화면 카카오 로그인 → 홈
- 기존 홈 관련 e2e 는 "둘러보기를 고른 비회원"으로 유지
