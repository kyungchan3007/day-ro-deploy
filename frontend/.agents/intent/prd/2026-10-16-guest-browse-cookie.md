## 문제
- `dayro_guest_browse` 에 유효기간이 없어 세션 쿠키로 남음
- 세션 복원 브라우저(크롬 "계속하기" · 모바일 사파리 · 크롬)에서는 사실상 계속 남음 → 비회원에게 시작 화면 · 온보딩이 다시 안 보임
- 로그아웃해도 둘러보기 쿠키가 남아 `/` 가 홈으로 감

## 사용자 결정 (2026-10-16)
- 둘러보기 쿠키 유효기간 24시간
- 로그아웃 시 둘러보기 쿠키 삭제

## 추가 결정 (사용자, 2026-10-16 2차)
- 게스트는 온보딩을 무조건 볼 수 있게: 웹사이트를 닫았다 다시 들어오면 24시간 안이어도 다시 시작 화면 · 온보딩
- 웹사이트를 닫지 않고 계속 돌아다니는 동안은 최대 하루(24시간) 홈 유지
- 회원은 온보딩 안 봄 · 로그아웃하면 바로 첫 화면(시작 화면 `/`)
	- (2026-10-17 정정) 로그아웃 후 다시 로그인하면 직전 화면으로 돌아가는 #181 동작은 유지 — 아래 "바뀌면 안 되는 규칙"

## 추가 결정 (사용자, 2026-10-17 3차 — Codex 2차 지적 반영)
- 30분 넘게 안 쓰다 돌아오면 새 방문 (브라우저 탭 복원 · 모바일 백그라운드 포함)
- 사이트를 열어둔 채 새 탭으로 들어오면 새 탭은 새 방문, 열어둔 기존 탭은 홈 유지

## 바뀌면 안 되는 규칙 (사용자, 2026-10-17 확인)
- 로그인 → 상황입력 중 로그아웃 → 다시 로그인하면 그 상황(단계 · 입력값)으로 돌아가야 함 (#181)
	- 2차에서 "로그아웃 → 시작 화면"으로 바꾸며 이 복귀를 지웠던 것을 되살림
	- 로그아웃 → 시작 화면 `/?next=<직전 화면>` → 시작 화면 카카오 로그인이 next 를 이어받아 로그인 뒤 그 화면으로

## 범위 밖
- 회원 탈퇴 시 삭제 (요청 범위 밖, 필요 시 별도)
- `/` 외 주소 직접 진입 시 시작 화면 노출 (지금처럼 막지 않음)

## 성공 기준
- 둘러보기 선택 후 쿠키에 `Max-Age=86400`
- 24시간이 지나면 `/` 에서 다시 시작 화면
- 로그아웃 응답에 둘러보기 쿠키 만료 → 로그아웃 후 바로 `/` 시작 화면
- 탭 · 브라우저를 닫고 다시 들어오면(새 탭) 시작 화면, 같은 탭 새로고침 · 화면 이동은 홈 유지
