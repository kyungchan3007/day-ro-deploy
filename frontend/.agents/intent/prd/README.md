# PRD Specs

이 디렉터리는 product-level intent를 저장한다.

## 언제 쓰는가
- 사용자 가치나 제품 정책 변화가 있는 작업
- 여러 세션 이상 이어질 큰 작업
- 여러 도메인 또는 공용 계약에 영향이 있는 작업

## 책임
- 왜 이 작업이 필요한가
- 어떤 사용자/운영 가치가 있는가
- 포함 범위와 제외 범위가 무엇인가
- 성공 상태를 어떤 제품 결과로 볼 것인가
