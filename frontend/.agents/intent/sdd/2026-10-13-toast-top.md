## 현재 구조
- `shared/ui/toast/Toast` = 프레젠테이션(다크 알약), `useToast` = 노출 · 자동 소멸
- 배치는 공용 규칙 없이 화면별 `.toastWrap` CSS
  - `widgets/situation` · `widgets/course-result`: 바닥 20px, z 30
  - `widgets/course-preview`: 바닥 96px, z 50
  - `features/auth/LoginNoticeToast`: 바닥 32px, z 50 (Tailwind)
  - `widgets/course-map/css` 미사용 `.toastWrap`

## Design Decisions
- `shared/ui/toast/ToastViewport` 신규 — 토스트 배치 전담
  - `position: fixed`, `top: calc(env(safe-area-inset-top) + 4rem)` (헤더 48px + 진행 바 · 간격)
  - 640 컬럼 가운데, 여러 토스트는 위에서부터 세로로 쌓음(gap 0.5rem)
  - z-index 60 (하단 시트 40 · 사이드 메뉴 · 확인 다이얼로그 50 위)
  - `pointer-events: none` (아래 화면 조작을 막지 않음)
  - 등장: 위에서 8px 내려오며 나타남 200ms, `prefers-reduced-motion: reduce` 면 애니메이션 없음
  - 자식이 없으면 렌더하지 않음
- 화면별 `.toastWrap` · `.stepGuide` 제거, 모두 `ToastViewport` 로 교체
- `Toast` · `useToast` 공개 API 변경 없음

## 레이어
- shared/ui/toast 안에서 완결, features · widgets 는 공개 배럴로 사용

## Risks
- 상단 토스트는 방금 누른 버튼과 거리가 멀다 → 짧은 완료 알림 위주라 영향 작음
- 상황 입력 첫 화면: 단계 안내가 "1/3" 표시 근처를 2초간 덮음 (버튼 가림보다 나음)
