# Agent Reports

이 디렉터리는 에이전트 작업 결과 리포트를 저장한다.

## Validation Reports
최종 검증 결과는 `.agents/reports/validation/`에 Markdown 파일로 저장한다.

파일명은 다음 형식을 따른다.

```text
YYYY-MM-DD-task-name.md
```

리포트에는 다음 내용을 포함한다.

- 작업 요약
- 요구사항 충족 여부
- 변경 파일 요약
- 테스트 결과
- 린트, 타입체크, 빌드 결과
- VSA 준수 여부
- 최종 결정
- 남은 리스크 또는 후속 작업
