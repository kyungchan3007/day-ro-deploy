# Static

SSR 렌더 대상의 **도메인별 정적 콘텐츠**(문구, 라벨, 약관 안내 등)를 둔다.
컴포넌트에서 텍스트를 분리해 서버 컴포넌트가 그대로 import 하도록 한다.

## 구조
```text
static/
  <domain>/index.ts   # 해당 도메인 화면의 정적 텍스트 상수
```

## 규칙
- 순수 데이터(상수)만 둔다. 컴포넌트 / 비즈니스 로직 / 훅 금지.
- 도메인 폴더 단위로 관리한다. (예: `auth`)
- 라우트가 확정되지 않은 링크는 `"#"` placeholder 로 두고 이후 교체한다.
- 위젯/피처는 이 상수를 import 해 렌더링만 담당한다.
