## ② CSP 위반 수집 · 보안 헤더 회귀 테스트 (#141)

- **배경** — Report-Only CSP 위반이 사용자 브라우저 콘솔에만 표시돼 운영에서 수집 불가
- **해결** — BFF `/api/csp-report`로 위반 수집(크기 제한 · 민감 정보 제거), `report-uri` · `report-to` 모두 지원
- **해결** — 보안 헤더 6종을 단위 테스트 · e2e로 검사해 설정 누락을 CI에서 차단
- **남은 작업** — 운영 위반 리포트 확인 후 CSP 강제 모드 전환

## ③ 엣지 보안 설정

- **접근 주소 단일화** — `workers.dev` · 버전별 미리보기 주소 비활성화를 설정 파일로 고정 (PR#159)
- **설정 파일로 고정한 이유** — 대시보드에서만 끄면 배포 때마다 기본값으로 다시 켜짐
- **리다이렉트 · HSTS** — `www` → `day-ro.com` 301, HSTS 6개월
- **요청 빈도 제한** — 코스 생성 API에 WAF 규칙(IP당 10초 5회 초과 시 10초 차단), 초과 시 전용 안내 문구 (#162)
