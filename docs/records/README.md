## 기록 규칙

- 한 기록 = 한 주제, 항목은 한 줄 개조식
- 기록 순서 — **배경 → 문제 → 해결 → 결과 → 근거**
- 수치는 측정 조건(개발 · 프로덕션 · Lighthouse 등)과 함께 기록
- 근거 칸에는 팀 저장소 `Dayro-dev/dayro`의 이슈 · PR 번호만 기록
- 미검증 항목은 "확인 필요"로 남기고 결과에 섞지 않음
