# 07. 구조 개선

## ① 코스 만들기 상태 URL 분리 (#129)

- **배경** — 코스 만들기 주소에 `requestId` · 후보 장소 · 선택 장소(장소명 JSON)가 포함
- **문제** — Meta Pixel이 주소 전체를 자동 수집해 코스 화면에서 Meta를 꺼 둔 상태 (코스 생성 · 저장 이벤트 미수집)
- **문제** — 장소명 · `requestId`가 방문 기록 · 서버 로그 · referrer에 남음
- **해결** — 진행 상태를 흐름 store로 옮기고 주소에는 단계(`step`)만 유지
- **결과** — 주소에 요청 · 장소 정보 미포함, 코스 화면 Meta 이벤트 재활성, 새로고침 · 뒤로가기 · 재추천 · 저장 회귀 없음

## ② 컴포넌트 · 컨트롤러 역할 분리 (#133)

- **배경** — 흐름 컨트롤러 훅 한 파일(334줄)에 이동 · 복원 실패 · 안내 · 토스트 · 단계별 액션이 혼재
- **배경** — 모달 포커스 트랩 · ESC · 스크롤 잠금 로직이 3곳에 중복
- **해결** — 마크업은 컴포넌트, 상태 · 이펙트는 커스텀 훅, 순수 규칙은 model · lib로 분리
- **해결** — 공용 `useModalDialog` · `useSelect` 추출, 흐름 컨트롤러를 이동 · 리다이렉트 · 안내 · 액션 훅으로 분리
- **결과** — 중복 모달 로직 단일화, 화면 동작 · 접근성 변경 없이 단위 테스트로 규칙 검증 가능
