## 항목별 결정 기록

- **#5 · #6 카카오 SDK 대신 og 메타 선택** — 카카오톡 · 문자 · 링크 복사 어디서나 같은 미리보기, SDK · CSP 변경 불필요
- **#5 · #6 서버 리다이렉트 미사용** — 미리보기 수집기가 리다이렉트를 따라가 네이버 메타를 읽기 때문, 브라우저에서만 이동
- **#5 · #6 메신저 수집기 head 전달** — Next 16 동적 메타 스트리밍으로 `kakaotalk-scrap` 등이 og를 못 읽는 문제를 `htmlLimitedBots`로 해결
- **#11 · #21 localStorage 인계** — 카카오 로그인이 새 탭으로 돌아올 수 있어 탭 단위 sessionStorage만으로는 복원 불가
- **#12 · #19 공유 방법 시트 선행** — 카카오톡 전용 버튼보다 모든 환경에서 동작하는 선택지를 먼저 제공
